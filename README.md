# CheckerByQR-code
 ระบบเช็คชื่อตามกิจกรรมที่จะมีผู้ใช้ด้วยกันสามารถสร้างกิจกรรมและตั้งค่าอณุมัติคนเข้าร่วมได้ว่าเป็นใครได้บ้างและส่ง Qr-coode ให้เพื่อสะดวกต่อผู้ที่จะเข้าร่วมกิจกรรมได้ง่าย และ ยังสามารถดูรายชื่อผู้เข้าร่วมได้ว่าเข้าร่วมตรงเวลาตามกำหนดหรือเข้าสายหรือไม่ได้เข้า รวมถึงมีฟังชั่นการแบ่งช่วงเวลาในการเช็คชื่อในหนึ่งวันเป็นกี่ช่วงด้วย และยังมีระบบ Admin ที่สามารถเข้าไปแก้ไขทุกส่วนของ user สร้างได้หมดทุกอย่าง <br/><br/>
 เป็นโปรเจ็คฝึกงาน ณ สำนักวิทยบริการและเทคโนโลยีสารสนเทศ มหาวิทยาลัยราชภัฏนครสวรรค์ 
 
## Features
<ul>
 <li> Connected Front end - Back end. </li>
 <li> Admin can edit datas. </li>
 <li> User have more options in create checker-events and Edits. </li>
 <li> Function to check the time as the activity is set. </li>
 <li> Can view each person's activity participation time. </li>
 <li> Can search for each person's name in the activity. </li>
 <li> Login Auths NSRU core </li>
 <li> Responsive design </li>
 <li> Statistical system </li>
 <li> Navigation bar </li>
</ul>
