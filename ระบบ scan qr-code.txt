ระบบ scan qr-code เข้าวิชาหรือเข้าร่วมกิจกรรม ระบบที่ 1
วิเคราะห์ความต้องการ:
	ต้องการเช็คเข้าร่วมอัตโนมัติผ่านการสแกน QR Code และนำข้อมูลรายชื่อเข้าไปในระบบ และรายงานการเข้าร่วมได้ และบันทึกข้อมูลการเข้าร่วม ร่วมถึงส่งข้อมูลที่บันทึกออกมาได้ในรูปแบบ excelได้

	ออกแบบ flowchart การทำงานของระบบ
	สร้าง template 
	สร้าง Admin dashboard (สำหรับผู้ควบคุมกิจกรรม)
	สร้าง Super Admin Dashboard 

กำหนดขอบเขต
	USER
		- แสกน QR Code ตามที่ขึ้นโชว์ที่หน้าจอ
		- แสกนเสร็จแล้วทำการกรอกข้อมูลสำหรับเข้าสู่ระบบ
		- เมื่อเข้าสู้ระบบเสร็จแล้วระบบจะทำการบันทึกรายชื่อและเวลาการเข้าร่วมกิจกรรมพร้อมแสดงแจ้งเตือนว่าเข้าร่วมกิจกรรมสำเร็จ 
		 หากมีข้อมผิดพลาดจะทำการแสดง Error 


	ADMIN (ผู้ดูแลการเช็คชื่อของกิจกรรมนั้น ๆ ) 
		- สร้างกิจกรรม
			- ตั้งชื่อกิจกรรม
			- ลบกิจกรรม
			- เปลี่ยนชื่อกิจกรรม
			-เพิ่ม ลบ แก้ไขรายชื่อนักนักศึกษาที่ต้องเข้าร่วมกิจจกรรม
			-นำเข้ารายชื่อโดยใช้ EXCEL ได้
			-ค้นหารายชื่อนักศึกษาได้
		- สร้าง QR Code เช็คชื่อ
			-กดสร้าง QR Code สำหรับเช็คชื่อ 
			-กดนับเวลาถอยหลังหมดเวลาเช็คชื่อสำหรับ QR Code ชุดแรก
			-สร้าง QR Code สำหรับเช็คชื่อใหม่ได้
			- ลบ QR Code ที่สร้างได้
			- ดูช่วงเวลาการเช็คชื่อได้
			- การเช็คชื่อหากมีการเช็คตามช่วงเวลา เช่น เช้า บ่าย เย็น จะใช้เวลาที่บันทึกเป็นเงื่อนไขในการแยก
		- ค้นหารายชื่อผู้เข้าร่วมกิจกรรมได้

	SUPER ADMIN
		- เพิ่มลบแก้ไขฐานข้อมูลทั้งหมดในระบบได้
		-ดูกิจกรรม และเปลี่ยนแปลงข้อมูลการเช็คชื่อกิจกรรมได้
		-ค้นหากิจกรรม
		-ค้นหารายชื่อ
		- มี Dashboard ดูสถิติ ต่าง ๆ
	
	1.ระบบต้องสามารถสแกน QR Code อย่างมีประสิทธิภาพโดยใช้อุปกรณ์พกพา
		- สร้าง QR Code จากweb QR code generater 
		
	2.ระบบต้องสามารถจัดการสิทธิการเข้าใช้ระบบของผู้ดูแลและผู้ใช้ได้อย่างมีประสิทธิภาพเช่นส่วนของนักศึกษา, ของอาจารย์
	3.ระบบต้องสามารถสร้างรายวิชาและกิจกรรมและบุคคลที่ต้องเข้าร่วมรายวิชาหรือกิจกรรมนั้นๆได้
	4.ระบบต้องสามารถบันทึกข้อมูลการเข้าร่วมและกิจกรรมของผู้ใช้เช่น ชื่อ,รหัสนักศึกษา,วิชา,วันที่,และเวลา ของแต่ละรายบุคคลได้
	5.ระบบควรสามารถสร้างรายงานและสถิติเกี่ยวกับการเข้าร่วมและกิจกรรม และแสดงข้อมูลในรูปแบบที่เข้าใจง่าย
	6.ระบบต้องมีอินเตอร์เฟซสำหรับผู้ใช้ที่ใช้งานง่ายและสะดวกสบาย ทั้งในการสร้าง QR code และการติดตามการเข้าร่วมและกิจกรรม
